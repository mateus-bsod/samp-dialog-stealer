# samp-dialog-stealer
Steal dialogue text from SAMP more easily!

# Usage
> OBS: you need to have [moonloader](https://www.mixmods.com.br/2020/10/moonloader/)!

1. open the dialog
2. press F6 with the dialog open and type command: /dialog
3. it will be saved in the "dialog_stealer" folder inside the root folder of your gta.
